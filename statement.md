# CinemaVault — Problem Statement and Scope

## Problem Statement

Moviegoers frequently experience long queues and manual hassle when booking tickets or purchasing food at cinemas. Managers face challenges in efficiently handling movie schedules, seat allocations, and order management without an integrated system. There is a need for a simple, automated, and modular solution that enables both customers and cinema management to streamline these operations in real-time.

## Project Objective

The objective of the CinemaVault project is to design and implement a user-friendly console-based application for movie ticket booking and food pre-ordering, utilizing modular Python coding principles. The project aims to provide secure, efficient workflows for booking, ordering, billing, and management, leveraging the programming concepts learned during the course.

## Scope

- Customer registration and login
- Manager authentication with password protection
- Add, view, and delete movies
- Assign and manage movie showtimes and ticket prices
- Book and cancel tickets with seat selection (including 3D glasses option)
- Manage a food menu and allow pre-booking and cancellation of food orders
- Simulated payment for bookings with automated bill/receipt generation
- Rate and review movies post-experience
- All features implemented through a menu-driven, text-based interface

## Functional Requirements

- At least three major functional modules:
    - Movie management (CRUD, showtimes, ticket prices)
    - Booking system (seats, tickets, payment, receipt)
    - Food ordering (menu management, pre-order, cancel)
- Secure login for customers and managers
- Clear input/output structure and robust error handling
- Full documentation with usage instructions

## Non-functional Requirements

- Modular and maintainable codebase (separate Python files for logic)
- User-friendly console interface for all roles
- In-memory data storage; no requirement for external databases
- Well-documented via comments and external documentation files (`README.md`, `statement.md`, report/PDF)
